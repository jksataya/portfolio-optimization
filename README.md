# Portfolio Optimization Using Python

## Project Overview
This project applies quantitative finance techniques to analyze stock market data and construct an optimized investment portfolio.

## Objectives
- Analyze historical stock prices and daily returns.
- Calculate annualized returns and volatility.
- Examine correlations between stocks.
- Optimize portfolio weights using the Sharpe Ratio.
- Visualize the Efficient Frontier.
- Compare the optimized portfolio against the S&P 500 (SPY).

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Methodology
The project uses historical stock data from AAPL, AMZN, GOOGL, MSFT, NVDA, and SPY.

Modern Portfolio Theory is applied to calculate portfolio risk and return. Portfolio weights are optimized to maximize the Sharpe Ratio.

## Key Results
- Optimal Annual Return: 43.35%
- Annual Volatility: 33.23%
- Maximum Sharpe Ratio: 1.184

The project also visualizes the Efficient Frontier and compares the optimized portfolio's historical performance with SPY.

## Conclusion
This project demonstrates how Python and quantitative methods can support portfolio analysis and investment research.

*Note: Results are based on historical data and do not guarantee future performance.*
